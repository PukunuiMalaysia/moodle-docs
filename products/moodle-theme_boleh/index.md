# Boleh

Boleh is a Boost child theme focused on a clean learning interface, branded site-home content, course cards, accessible Moodle navigation, optional dual-brand headers, and configurable imagery.

## Requirements and installation

- `main` supports Moodle 5.0 through 5.2. Moodle 4.5 LTS is maintained separately on `MOODLE_405_STABLE` for bug and security fixes.
- Install the release ZIP through Moodle's normal plugin installer, complete the upgrade, and select **Boleh** under **Site administration > Appearance > Theme selector**.
- No Composer, npm, Grunt, or post-install build is required.

## Configuration

Administrator settings are grouped into Branding and appearance, Navigation, Course display, Site home header, Site home content, Footer, Advanced, and About. Administrators can configure logos, masthead, colours, spacing density, course display, site-home image or MP4, banner and quick-link content, login background, footer, accessibility controls, and site-specific SCSS.

After media or style changes, purge Moodle caches and verify guest and signed-in homepages, login, dashboard, course and activity pages, administration, drawers, and mobile layouts. Keep Moodle's primary navigation, user menu, messages, notifications, edit switch, course index, and block drawer available.

See [Moodle version support](version-support.md) for the maintained branch policy.

## Privacy and support

Boleh stores user preferences for accessibility toolbar visibility, font size, colour mode, and font type. These preferences are declared and exported through Moodle's Privacy API.
