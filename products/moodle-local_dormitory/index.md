# Dormitory

Dormitory provides Moodle administration pages for accommodation, meals, and transport, together with calendar synchronization for selected course categories.

## Requirements and installation

- The current package declares a Moodle 3.2 minimum. Confirm compatibility in staging before using it on a newer Moodle release.
- Install at `local/dormitory` and complete Moodle's normal upgrade.
- Configure course categories, calendar link text, floor and room information, meal categories and menus, transport routes, and the date filter under the plugin settings.

## Administration

Authorised administrators can maintain accommodation entries, room maintenance, meal allocations, menus, transport movements and routes, then export relevant records. The calendar synchronization can create site events from dates belonging to courses in selected categories.

## Privacy warning

Accommodation, meal, and transport records can identify users and may include travel and schedule information. Limit access to authorised staff, apply an appropriate retention policy, and test Moodle privacy export and deletion before production use. The current plugin privacy declaration should be reviewed against the deployed feature set before Marketplace submission.
