# Plugin health report

Plugin health is a Moodle administrator report for assessing declared third-party plugin compatibility, available update paths, dependencies and aggregate usage before a Moodle upgrade.

## What it provides

- On-demand checks for Moodle 4.5 through 5.2.
- Clear Ready, Update required, Blocked, Manual review and Unknown states.
- Local plugin and dependency evidence alongside official Moodle plugin metadata.
- CSV and JSON upgrade action registers.
- Conservative handling of private, custom, free and paid plugins.

The report does not install packages or guarantee functional compatibility. Complete staging and regression testing before every production upgrade.
