# Skills Matrix

Skills Matrix is a system report that combines Moodle users, course completion, competencies, scales, and selected profile fields into a filterable matrix with a downloadable report.

## Requirements and installation

- Moodle 4.0 or later as declared by the current package.
- Install at `report/skillsmatrix`, complete Moodle's upgrade, and configure its administrator settings.
- Grant `report/skillsmatrix:view` only to roles that need site-wide competency and completion information.

## Administration and privacy

The report can display user identity and profile data alongside competency and completion results. Filters and downloaded files therefore contain personal educational records. Restrict the capability, protect exports, and define a retention and sharing policy appropriate to the organisation.

The current plugin package should be reviewed for complete Privacy API coverage, portable database queries, and supported-version validation before Marketplace submission or deployment to a new Moodle release.
