# Aurora

Aurora is a Boost child theme with dark and light colour modes, configurable branding, front-page media, course cards and headers, footer content, and user display preferences. This documentation follows the Moodle 5.2 maintenance branch.

## Requirements and installation

- Moodle 5.2 for this documented branch, with the Boost theme available.
- Install at `theme/aurora`, complete Moodle's upgrade, select Aurora under **Site administration > Appearance > Theme selector**, and purge caches.
- Administrators do not need to run build tools after installing the release package.

## Configuration

Aurora settings cover mode-specific and fallback logos, favicon, colour tokens, gradient, font pairing, colour mode, density, course-card and course-header presentation, front-page image or video, structured footer content, and site-specific SCSS.

Use compressed, wide media with important content centred. Prefer settings over custom SCSS, and test customisations on login, dashboard, course, quiz, assignment, grading, administration, drawers, and mobile layouts after each Moodle upgrade.

Signed-in users can select dark or light mode. Moodle stores that selection as a user preference.

## Privacy and support

Aurora stores ordinary theme configuration and a user colour-mode preference. It does not add an external analytics or advertising service.
